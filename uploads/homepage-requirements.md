# 个人学术主页 — 需求说明文档

> 本文档用于交付给 Claude Design 制作个人学术主页。
> 所有标注为"占位符 / placeholder"的内容由作者后续自行替换。

---

## 0. 总体概述

- **类型**：个人学术主页（personal academic homepage）
- **作者身份**：本科生（undergraduate student）
- **部署环境**：GitHub（GitHub Pages）
- **技术栈**：纯 HTML 编写（配合 CSS / 必要的少量 JS）
- **页面构成**：
  - `index.html` — 主页（单页滚动）
  - `gallery.html` — 照片墙独立页面
- **语言**：双语（中 / 英），**默认英文**，可一键切换；切换按钮位于顶部导航栏最右侧
- **响应式**：需做移动端适配（见各节说明）

---

## 1. 视觉风格

### 1.1 配色
- 整体以**浅色调**为主。
- 需提供**三套配色方案**，分别为：**深绿色系 / 红色系 / 深蓝色系**。
- 三套配色通过 **CSS 变量集中管理**，在源代码中保留一处可切换的选项（例如顶部注释 + 一组 `:root` 变量），作者改一个值即可整体换肤。
- **默认配色：深绿色系**。
- 主色/点缀色用于：链接、标题下划线、小标签（pill）、导航高亮等处。

### 1.2 字体
- **英文：serif 衬线体**（如 Georgia 等，体现书卷气）。
- **中文：思源宋体（Source Han Serif / Noto Serif CJK）**。

---

## 2. 页面整体结构（主页 index.html）

### 2.1 顶部导航栏
- **全宽**，**固定在顶部**（滚动时始终可见）。
- 点击条目跳转到页面对应位置。
- **导航五项**（从左到右）：
  1. **About**
  2. **Curriculum Vitae**（导航中用拉丁文全称显示，建议大写小字距样式 `CURRICULUM VITAE`；中文界面此项**保留拉丁文写法** *Curriculum Vitae*）
  3. **Publications**
  4. **Gallery**
  5. **语言切换键（EN / 中）** —— 位于导航栏**最右侧**
- 跳转行为：
  - About / Curriculum Vitae / Publications → 本页内**锚点跳转**
  - Gallery → 跳转到独立页面 `gallery.html`

### 2.2 双栏布局
- **左栏（约 1/3 宽度）**：个人信息区，**sticky 固定**——右栏内容向下滚动时，左栏照片与联系方式始终可见。
- **右栏（约 2/3 宽度）**：具体内容，从上到下依次为 **About Me → CV 各模块**。
- **移动端适配**：双栏在小屏自动**堆叠为上下单栏**。

---

## 3. 左栏 — 个人信息区

- **照片**：一张作者照片，**矩形竖排**。
- **姓名显示**：
  - 默认英文名写法：**Peiwen (Lucas) Zhou**
  - 中文名：**周培文**
  - **英文界面**：英文名后加括号注明中文 → `Peiwen (Lucas) Zhou（周培文）`
  - **中文界面**：同样需注明英文名 → `周培文（Peiwen (Lucas) Zhou）`
- **身份**：Undergraduate Student
- **当前院校**：中国农业大学（China Agricultural University）
- **邮箱**（防爬虫写法，原样照抄）：`zhoupwyz [at] outlook [dot] com`
- **ORCID**：占位符链接 / ID
- **GitHub**：占位符链接（放图标）
- **LinkedIn / 领英**：占位符链接（放图标）
- 注：**不需要** CV/PDF 下载链接；**不需要** Google Scholar。

---

## 4. 右栏 — 内容区

### 4.1 About Me
- 一段自我介绍。**内容用占位符**。

### 4.2 Curriculum Vitae（CV）
CV 各子模块，按以下顺序与字段排版：

**(1) Education（教育经历）— 3 条**
每条三行：
- 第一行：学校名称
- 第二行：年份
- 第三行：绩点（GPA）等
- 内容用占位符。

**(2) Certifications and Achievements（获奖和证书）— 3 条**
- 内容用占位符。

**(3) Research Experience（研究经历）— 2 条**
每条三行：
- 第一行：研究主题
- 第二行：指导老师和合作同学
- 第三行：日期
- 内容用占位符。

**(4) Publications（学术发表）— 目前 1 条（预计未来增多）**
每条三行：
- 第一行：标题
- 第二行：期刊 · 日期
- 第三行：作者列表（**作者列表中作者本人的名字加粗**）
- 真实内容暂缺，**用占位符**，结构示例：
  - `[Paper Title]`
  - `[Journal], [Date]`
  - `[Author A, **Peiwen (Lucas) Zhou**, Author C]`
- 该模块标题需保留（为后续新增发表预留空间）。

**(5) Skills（技能）**
分三组，用**浅色小标签（pill）平铺**呈现（不使用进度条）：
- **Courses（学过的课程）**
- **Languages（语言）**
- **Skills / Tools（技能 / 工具）**
- 内容用占位符。

---

## 5. Gallery 页面（gallery.html）

- **独立成页**，从主页导航栏 Gallery 进入。
- **风格与主页统一**（同一套配色 / 字体）。
- 页面**顶部带导航**，包含返回主页的入口。
- **形态：竖向信息流**（类似"朋友圈"动态流）：
  - 一条条卡片**自上而下排列**
  - **按时间倒序**（最新在上）
  - 每条字段 = **配图 + 一句话描述 + 地点 + 日期**
  - 语义：标明"何年何月何日、在何处、做了什么"
  - **允许纯文字条目**（某些动态可无配图）
- 内容用占位符。
- 移动端同样需适配。

---

## 6. 双语切换说明

- 默认英文，点击导航栏最右侧切换键在 **EN / 中** 之间切换。
- 切换范围覆盖全站文案（导航、各模块标题、正文、Gallery 等）。
- 特例：导航中 "Curriculum Vitae" 一项在中文界面下**仍保留拉丁文写法**。
- 姓名在两种语言下均需中英并列（见 §3）。
